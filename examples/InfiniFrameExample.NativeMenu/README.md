# Native Menu Example

Demonstrates building a desktop window with a rich native menu bar using the InfiniFrame API.

## What It Shows

- Multi-level menu hierarchy (File, Edit, View, Help) with submenus and separators
- Keyboard shortcuts on menu items
- Dynamic menu item state management (enable/disable, show/hide)
- Bidirectional C#-to-JS communication via web messaging for menu actions

## Run

```bash
dotnet run
```
